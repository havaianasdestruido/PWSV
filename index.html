Core Features

Built for Performance & Precision

Engineered in modern C++17 to deliver robust, zero-allocation socket streaming directly from your audio host.

Microsecond Transport Sync

Queries DAW playhead metrics (time in seconds, sample frames, PPQ position, BPM, bar numbers, beat offsets) with exact sub-block precision.

Polyphonic MIDI Streaming

Captures live and sequenced NoteOn/NoteOff events, tracking pitch numbers, velocity dynamics, and 16-channel routing simultaneously.

Triple Timing Engines

Choose between fixed frequency (Hz Mode), musical grid quantization (Beats Mode with 10 subdivisions), or events per minute (Minutes Mode).

VST3 & CLAP Architecture

Supports industry-standard VST3 and next-generation CLAP plugin specifications, compatible with Ableton, FL Studio, Reaper, Bitwig, and Cubase.

Zero-Dependency Cryptography

Custom pure C++ SHA-1 and Base64 implementations provide compliant RFC 6455 opening handshake handling without external libraries.

Non-Blocking Thread Safety

Dedicated worker thread runs non-blocking socket polling (`select()`) so your DAW audio engine experiences zero latency and zero drops.

Quick Start

Connect in Any Language

Standard RFC 6455 WebSockets make integration with your stack effortless.

// Connect directly from any modern web browser
const ws = new WebSocket("ws://127.0.0.1:8080");

ws.onopen = () => console.log("Connected to PWSV!");

ws.onmessage = (event) => {
  const telemetry = JSON.parse(event.data);
  console.log(`BPM: ${telemetry.bpm} | Bar: ${telemetry.bar} | Beat: ${telemetry.beat}`);
  
  if (telemetry.notes.length > 0) {
    console.log("Active Notes:", telemetry.notes);
  }
};
# Run without installing any pip packages using sample/test_ws.py
import socket, json
from sample.test_ws import connect_ws, recv_frame

sock = connect_ws("127.0.0.1", 8080)
while True:
    data = recv_frame(sock)
    if not data: break
    d = json.loads(data)
    print(f"Time: {d['time_sec']}s | Playing: {d['playing']} | Notes: {d['notes']}")
